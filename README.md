# 💳 Interactive Card Details Form

This is a responsive form that allows users to input their credit card details and see a real-time preview on a virtual card. The project includes client-side validation and error handling for all fields.

## 🌐 Live Demo

👉 [View the live project here](https://callmehelga.github.io/interactive-card-form-DOM/)

## 🚀 Features

- Real-time preview of cardholder name, card number, expiration date, and CVC
- Input formatting (e.g., card number spacing)
- Validation for all fields
- Responsive design for mobile, tablet and desktop
- "Thank You" confirmation screen after successful submission

## 🛠 Built With

- HTML5
- CSS3 (Flexbox + Media Queries)
- JavaScript (Vanilla)
  → **DOM manipulation** for dynamic updates and validation
